# HANDOFF — сайт ManeVRit for Brands

Статический сайт на GitHub Pages: https://manevritforbrands.github.io
Репозиторий `manevritforbrands/manevritforbrands.github.io`, публикуется ветка **`main`**.
Рабочая ветка разработки — `claude/optimistic-goldberg-eedthq`; в неё коммитят, затем fast-forward в `main`.
Никакой сборки: HTML + один CSS + один JS. Бриф заказчика — `missions/09_WEBSITE.md` в репозитории `manevritforbrands/claude-design-brain`.

## 2. Дизайн-система (конкретные значения)

### Цвета — `:root` в `css/site.css`
```
--black  #000       фон всего сайта
--screen #0b0b0b    подложка под фото/видео, пока грузятся
--light  #ece7dd    основной текст, активное меню
--dim    #a9a399    второстепенный текст, подписи, курсив
--line   #2a2a2a    линии, рамки, разделители
```
Прочее: текст абзацев в «О студии» и списках — `#d6d0c5`; разделитель между предложениями на «Стоимости» — `1px dashed #333`; фон карточки контактов — `#0e0e0e`, рамки кнопок в ней — `#3a3a3a`.

### Шрифты (лежат в `fonts/`, подключены через `css/fonts.css`; в `<head>` предзагружены Forum latin и Old Standard normal cyrillic)
```
--cap  'Forum'            капители: меню, заголовки секций, MANEVRIT
--text 'Old Standard TT'  весь текст, курсив (for Brands, подписи)
```
Базовый текст: `400 17px/1.6 var(--text)`.
Меню и мелкие титры (`.caps`, `.nav a`): `13px`, `letter-spacing:.24em`, `uppercase`, opacity `.72` → `1` при наведении и на текущей странице (подчёркнута 1px).

### Титр бренда `.brand` (главная, карточка контактов)
- `MANEVRIT`: Forum, `clamp(34px,5.2vw,88px)`, `letter-spacing:.32em`, `margin-right:-.32em` (компенсация разрядки).
- `for Brands`: Old Standard TT italic, `clamp(28px,4.2vw,70px)`, в одну строку с MANEVRIT, `gap:.45em`, по базовой линии.
- Малый вариант `.brand.small`: `clamp(22px,2.6vw,40px)` / `clamp(19px,2.1vw,32px)`.
- На телефоне (≤760px) — две строки: `10.5vw` / `8vw`.
- Буквы проявляются по одной: `.l` — `opacity 0 + blur(8px)` → `1`, шаг 70 мс, длительность 1.6 с.

### Заголовки секций `.section-title`
Forum, `clamp(26px,3vw,46px)`, `letter-spacing:.28em`, uppercase, по центру, отступ снизу `clamp(40px,5vw,72px)`.

### Сетка и отступы
```
--gutter            clamp(16px,3vw,48px)   боковые поля везде
.section            padding: clamp(80px,12vw,180px) var(--gutter)
.page-head.tight    padding: clamp(40px,6vw,90px) var(--gutter) clamp(28px,3vw,48px)
.groups.wide        max-width 1800px, между строками clamp(70px,8vw,130px)
.row.r5             5 колонок, gap clamp(8px,1vw,14px)
.latest             2 колонки, max-width 1480px, gap clamp(16px,2vw,28px)
.about              5fr / 6fr, max-width 1280px, gap clamp(32px,6vw,110px)
.offers             max-width 1320px; .offer = 5fr / 6fr, gap clamp(28px,5vw,90px)
```
Точки перелома: `760px` (телефон), `860px` (сетка «Стоимости» и «вход → выход» в одну колонку), `900px`.
На телефоне строка серии фото превращается в горизонтальную ленту с прокруткой (карточка `68vw`, `scroll-snap`); общий список роликов (`#all` на `video.html`) — сетка в 2 колонки.

### Пропорции
- Кадр на главной `.reel`: **2.39:1**, `max-height:62svh`; на телефоне 4:5. Сверху и снизу чёрные «шторки» с меню и титром.
- Превью видео и фото в сетке: **4:5**.
- Видео рядом с тарифами и «Последние проекты»: 16:9.
- Фото Расула: 2:3.

### Движение
```
--ease cubic-bezier(.16,1,.3,1)
```
- Главная: шторки съезжаются за 2 с `cubic-bezier(.7,0,.2,1)`, меню и подпись проявляются с задержкой 2.6–3 с.
- Ролики на главной: смена каждые **3000 мс** (`EVERY` в `js/site.js`), наплыв `opacity .55s`.
- Проявление блоков при прокрутке: `translateY(28px)` → 0, 1.2 с, в строке шаг 90 мс.
- Переход между страницами: `@view-transition` — уход 0.35 с, появление 0.6 с.
- Бегущая лента: 70 с на круг, пауза при наведении.
- При `prefers-reduced-motion` всё выключается.

## 4. Решения, которые нельзя менять

- **Стиль «Кино»**: чёрный фон `#000`, капители Forum с разрядкой, курсив Old Standard TT. Заказчик выбрал его из ~20 вариантов. Не добавлять другие шрифты, цветные акценты, градиенты, скругления, тени.
- **Главный экран = один кадр 2.39:1 с роликами, которые сменяются каждые 3 с.** Заказчик отказался от стены из нескольких окон и от коллажа («копия Алины»).
- **Титр одной строкой: MANEVRIT + for Brands курсивом.**
- **Портфолио — по 5 в строке, строка = одна серия.** Состав строк из `assets/ASSETS.md` не разбивать и не дополнять чужими работами. Неполную строку оставлять неполной.
- **Видео в сетке — превью 4:5 с красивым кадром, открываются в плеере со звуком** (как на alinasozdaet.ru). Не возвращать автопроигрывание 16:9 в полную ширину.
- **H.264 первым источником**, пока AV1 не пережат из исходников (см. п. 6 выше). Без плёночного зерна и фильтров поверх роликов — заказчик жаловался на качество.
- **Подписи только «Творческая работа»** или реальное имя клиента. Не выдумывать клиентов, цифры, отзывы, цены.
- **Ролик для отеля не ставить** — клиент его забраковал.
- **`lake-tailoring.jpg` не показывать второй раз**, если он вернётся на сайт.
- **WebP для фото без JPEG-фолбэка** — решение заказчика (ASSETS.md).
- **Меню**: Главная · AI-видео · AI-фото · Стоимость · Контакты. «Контакты» — не страница, а карточка поверх (`<dialog id="contact">`).
- **Старые фото и исходники старых роликов не удалять** — просьба заказчика.
- **Минимум текста.** Заказчик убирал лишние подзаголовки; не добавлять надписи-«этикетки» над заголовками.

## Кэш
GitHub Pages отдаёт CSS/JS с кэшем ~10 минут. Поэтому у `css/site.css`, `css/fonts.css`, `js/site.js` в каждом HTML стоит `?v=ГГГГММДДЧЧММ`. **После любой правки CSS или JS обновить это число во всех пяти HTML** — иначе у посетителей новая разметка встретит старые стили и страница «развалится».

## Как проверить локально
Открыть `index.html` в браузере. Слоты и «вход → выход» используют `fetch`, поэтому для них нужен локальный сервер: `python3 -m http.server` в корне и http://localhost:8000.
