# CONTENT_SLOTS — места под ролики, которых пока нет

Слоты уже стоят на странице `video.html` как `<template class="slot">` внутри сетки по пять. Пока файла нет, превью не рендерится и сетка не меняется.
Чтобы превью встало в сетку: положить файлы с именем из таблицы и вписать это имя в `content.json` → `slots`, например `"slots": ["niche-fashion"]`. Превью встанет после существующих роликов, в порядке таблицы; по клику открывается в плеере. Пока имени нет в списке, сайт файл не ищет (раньше проверял каждый слот запросом к серверу и получал 404).

**Что положить на каждый ролик (четыре файла):**

```
assets/videos/niche-ИМЯ.av1.mp4    основной, AV1, 24 fps
assets/videos/niche-ИМЯ.h264.mp4   запасной для Safari до 17
assets/posters/niche-ИМЯ.jpg       постер для плеера, кадр целиком, JPEG
assets/thumbs/niche-ИМЯ.webp       превью в сетке: самый красивый кадр, вырез 4:5, 800×1000
```

H.264 стоит первым источником: присланный AV1 при текущем битрейте заметно мылит детали, поэтому AV1 оставлен запасным, пока не пережат из исходников с запасом по качеству.

Сжатие — по рецепту из брифа (AV1 crf 32 + H.264 crf 22, 24 fps, разрешение не трогать). Подпись по умолчанию «Творческая работа»; если ролик сделан для клиента — поменять текст в `<p class="note">` этого слота на имя клиента.

## Осторожно

- **Отели, рестораны, недвижимость.** Заказчик знает свой объект наизусть и мгновенно ловит несоответствие. Ролик собирается только из реальных фото объекта; никаких придуманных интерьеров, видов из окна и планировок.
- **Ролик для отеля, который клиент забраковал, не ставить** — ни в слот, ни куда-либо ещё.
- Клиентов, цифры и отзывы не выдумывать. Нет подтверждённого клиента — подпись «Творческая работа».

## Главная · блок «вход → выход»

Слева — исходные фотографии, которые прислал заказчик, справа — готовый ролик. Снимает главное возражение клиента: «у нас нет материала для рекламы».
Блок стоит на `index.html` (`#input-output`) скрытым. Чтобы он появился — положить кейс и поставить в `content.json` `"case": true`:

```
assets/input-output/case-01/case.json
assets/input-output/case-01/in-01.jpg … in-NN.jpg   исходники заказчика как есть, с телефона
assets/input-output/case-01/result.av1.mp4          готовый ролик, AV1
assets/input-output/case-01/result.h264.mp4         запасной H.264
assets/input-output/case-01/result.jpg              постер
```

`case.json`:
```json
{
  "photos": ["in-01.jpg", "in-02.jpg", "in-03.jpg"],
  "result": "result",
  "caption": "10 фотографий с телефона → ролик за день, без съёмки"
}
```

- Соотношение ролика — родное (обычно 16:9), хронометраж 15–30 с.
- Доказывает: из обычных снимков товара или помещения получается готовая реклама со звуком, цветом и типографикой, без съёмочной смены.
- Подпись пишется по фактам этого кейса: реальное число фото и реальный срок. Ничего не округлять в свою пользу.
- Исходники показывать только с согласия заказчика.
